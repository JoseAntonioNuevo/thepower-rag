# S9 · PostgreSQL y pgvector

Objetivo para el alumno: dotar a los agentes de memoria persistente y de búsqueda semántica sobre datos propios.

Contenido del temario: fundamentos de embeddings y similitud vectorial, bases de datos vectoriales, PostgreSQL, pgvector, herramientas de gestión y monitorización, e integración de la base vectorial con modelos de lenguaje y con MCP.

Ejercicio localizado: RAG multi-tenancy, con aislamiento de datos por cliente y organización. La fuente no trae rúbrica, esquema, dimensión ni plazo.

Esta sesión enseña PostgreSQL y pgvector. La demostración de la clase de RAG de este repositorio usa Vectorize, D1 y R2. Esa adaptación no cambia lo que esta sesión enseña.
