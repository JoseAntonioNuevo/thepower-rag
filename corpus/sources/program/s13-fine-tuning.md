# S13 · Fine-tuning y LoRA

Objetivo para el alumno: especializar un modelo cuando el prompting y el RAG no bastan.

Contenido del temario: fundamentos de fine-tuning, preparación de entornos y datos, supervised fine-tuning, LoRA y PEFT, cuantización y QLoRA, merge y despliegue del modelo adaptado.

Ejercicio localizado: fine-tuning multimodal. La fuente no trae rúbrica, dataset, plazo ni una pila concreta.
