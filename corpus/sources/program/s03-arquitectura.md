# S3 · Arquitectura de sistemas conversacionales

Objetivo para el alumno: diseñar la arquitectura de una aplicación de IA antes de escribir código y sentar las bases conceptuales de los agentes.

Contenido del temario: fundamentos de arquitectura de software, requisitos funcionales y no funcionales, patrones de diseño, estructura de carpetas y separación de capas, documentación y el patrón ReAct explicado paso a paso.

Ejercicio localizado: arquitectura de extremo a extremo. Consiste en diseñar y poner en marcha la estructura de carpetas y la separación de capas de un proyecto. No hay rúbrica ni plazo en la fuente.
