# S15 · MCP

Objetivo para el alumno: entender y construir sobre el Model Context Protocol para conectar modelos con herramientas y datos.

Contenido del temario: qué es MCP, arquitectura, primitivas, construcción de un servidor, MCP Inspector, consumo desde un agente, autenticación, autorización, seguridad, gobernanza empresarial y la comparación con A2A.

Ejercicio localizado: construir un servidor MCP propio que expone una herramienta y un recurso de negocio, conectarlo a un agente y verificar su funcionamiento. No hay rúbrica ni plazo en la fuente.
