# S16 · Despliegue en AWS

Objetivo para el alumno: llevar una pequeña API de IA de local a AWS entendiendo contenedor, red, permisos, secretos y coste.

Contenido del temario: proveedores cloud, AWS básico, comparación con Azure y GCP, cómputo, almacenamiento, red, seguridad, optimización de costes, Docker y un primer vistazo a servicios de IA gestionada. El título del ejercicio es desplegar una aplicación con Docker.

Ejercicio resumido en la guía: API FastAPI con salud y una llamada de IA, Dockerfile y despliegue de demostración en ECR y ECS/Fargate. Los secretos van en Secrets Manager o Parameter Store. Estimar 730 horas sin mantener los recursos un mes, y documentar la limpieza. La dedicación orientativa es de 4 a 6 horas.
