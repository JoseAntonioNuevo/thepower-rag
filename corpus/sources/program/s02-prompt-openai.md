# S2 · Prompt engineering y OpenAI

Objetivo para el alumno: dominar las técnicas de prompting que siguen siendo la base de un sistema de IA generativa y dar los primeros pasos con la API de OpenAI.

Contenido del temario: anatomía de un prompt, zero-shot, few-shot y chain of thought, system prompt frente a user prompt, JSON mode, prompting ReAct, prompting para código y análisis de datos, iteración y evaluación de prompts, seguridad y OpenAI.

Ejercicio localizado: uso de OpenAI mediante prompt injection para intentar saltarse los guardarraíles de un sistema con instrucciones protegidas. No hay rúbrica ni plazo en la fuente.

El texto original conserva erratas como «Propmt» y «guardarailes». Esta ficha normaliza la ortografía y no añade requisitos.
