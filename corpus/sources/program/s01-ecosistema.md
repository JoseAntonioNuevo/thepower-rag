# S1 · Ecosistema actual

Contenidos de la sesión S1 del programa: ecosistema actual, parámetros de generación y selección de modelo.

Objetivo para el alumno: situar modelos, frameworks y protocolos del ecosistema actual antes de entrar en el detalle de cada uno.

Contenido del temario del 17 de julio de 2026: qué son los LLM, parámetros de generación, comparativa de modelos, diferencia entre aprendizaje automático, deep learning e IA, costes y optimización, y modelos propietarios frente a código abierto.

Ejercicio localizado: selección de modelo. Hay que justificar, para un caso de negocio, la elección de proveedor o modelo con criterios técnicos y económicos. La fuente no trae rúbrica, plazo ni un enunciado más largo.

Estas referencias describen el temario. No certifican que un modelo o una API sigan disponibles.
