# S7 · Modelos abiertos

Objetivo para el alumno: entender cuándo compensa un modelo abierto frente a un modelo cerrado por API, y comparar mejorar el prompt con especializar el modelo.

Contenido del temario: ecosistema Hugging Face, generación de texto, prompting aplicado a modelos abiertos, fine-tuning y datasets, y despliegue en el Hub.

La guía añade LoRA, publicación y reutilización, y los costes de control, infraestructura y mantenimiento.

Ejercicio resumido: clasificar incidencias ficticias y producir JSON con categoría, prioridad y respuesta breve. La referencia enviada es Qwen3-0.6B con Transformers, Datasets, TRL y PEFT. Separar entrenamiento, validación y test. Comparar base con instrucciones, base con few-shot y ajuste LoRA. Pedir JSON como texto, sin modo JSON ni reintentos correctores. Publicar el adaptador en Hugging Face Hub. La dedicación orientativa es de 5 a 7 horas con GPU, aparte de las esperas. El título del temario es fine-tuning de un modelo de texto abierto.
