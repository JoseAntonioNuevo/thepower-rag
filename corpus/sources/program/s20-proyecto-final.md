# S20 · Proyecto final

Objetivo para el alumno: integrar lo aprendido en un proyecto de principio a fin.

Temario: introducción y planificación, prompts y configuración del agente, construcción del grafo, módulos y herramientas, aplicación, integración con PostgreSQL, integración con Langfuse, exposición mediante FastAPI, integración con MCP y despliegue en AWS. También una extensión de Deep Research combinada con recuperación sobre información propia.

Ejercicio del temario: entrega de este proyecto final.

Límite de las fuentes: no consta un enunciado final detallado, una rúbrica, una fecha límite de entrega ni si la sesión es construcción, revisión o defensa. No hay que atribuir esos detalles. La guía tampoco documenta una dedicación orientativa.
