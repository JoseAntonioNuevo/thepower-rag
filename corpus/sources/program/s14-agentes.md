# S14 · Agentes

Objetivo para el alumno: pasar de un agente aislado a un sistema de varios agentes, y entender los trade-offs de los frameworks citados para 2026.

Contenido del temario: agente único con herramientas, equipos especializados, orquestación, patrones de coordinación, persistencia y memoria compartida, errores y reintentos, protocolo A2A, observabilidad y coste. Los frameworks nombrados son LangGraph, CrewAI, AutoGen, OpenAI, Google ADK y Microsoft Agent Framework.

Ejercicio localizado: convertir un agente conversacional en un sistema de dos o tres agentes especializados usando LangGraph o CrewAI y comparar ambas implementaciones. No hay rúbrica ni plazo en la fuente.
