Remaining issues for the actual executor phase:

1. The production executor is deliberately disconnected. scripts/activate.ts never supplies spawn; scripts/activation.ts invokes a void callback and does not inspect an asynchronous operation's outcome. Connecting the executor needs awaited command-specific operations, validated results, nonzero failures and receipts; not just changing the exit code to zero.

2. Normal Vectorize propagation delay is classified as failure. Isolated fake ports accepted an upsert and returned a mutation ID, then returned no visible vectors yet. runIngestion returned phase failed with vectorize-readback-incomplete. This should remain pending-visibility with bounded subsequent reads; do not re-embed or upsert again solely to poll. Real rejection/corruption must still be a failure. No remote calls were made in the reproduction.

3. The journal is not durably written by the bound adapter. The ingest_items table exists, but a completeness-sensitive source search found no INSERT/UPDATE into it in apps/scripts/packages. The core returns journal items in memory; recordPhase updates index_profiles only. Persist each operation receipt/failure and restore it on resume before claiming durable recovery.

4. Profile manifests share an object key. Different model/dimension profiles legitimately share preparationId, but each embeds different profile metadata in corpus/<preparationId>/manifest.json. A reproduction produced different profile IDs/bodies at the same key. Use a profile-scoped manifest/receipt key, keeping immutable shared source documents/content manifests separate. Preserve earlier profiles.

5. The missing metric is an adapter gap, not a missing Cloudflare capability. Installed Vectorize binding describe() does not expose metric, but Cloudflare's administrative GET /accounts/{account_id}/vectorize/v2/indexes/{index_name} returns result.config.dimensions and result.config.metric. Project Wrangler 4.147.0 supports vectorize get <name> --json (help checked). Use authenticated management readback during activation and store a receipt; do not hardcode cosine or put management tokens in the Worker/browser.
